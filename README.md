## Proposed Project Architecture

AutoCyber is planned as a monorepo-based application with a Next.js frontend and Python FastAPI backend.

The following directory structure represents the proposed project architecture. It is provided to help potential collaborators understand the development scope, technology choices and organization of the project.

The structure may evolve as development progresses and new requirements emerge.

### Planned Technology Stack

| Component | Technology |
|---|---|
| Frontend | Next.js |
| Programming Language | JavaScript |
| Styling | Vanilla CSS |
| UI Components | shadcn/ui |
| Backend | Python + FastAPI |
| API Architecture | REST API |
| Application Architecture | Modular Monolith |
| AI Integration | AI APIs, automation and intelligent systems |
| Version Control | Git + GitHub |
